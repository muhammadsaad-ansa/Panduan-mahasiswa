# MahasiswaHub — Portal Website Penting Mahasiswa

Website direktori terkurasi yang menggabungkan seluruh platform penting untuk mahasiswa ke dalam satu halaman interaktif (siap di-upload ke **GitHub Pages**).

## Fitur Utama
- **Direktori 17 Platform Inti Mahasiswa:** Riset & Jurnal, Catatan & Kolaborasi, Penulisan & Presentasi, Coding/Data/Skill, serta Karier/Magang/Beasiswa.
- **Pencarian Cepat & Paket Mode:** Filter kategori atau gunakan tombol paket cepat (*Mode Skripsi*, *Mode Tech & Data*, *Mode Magang & CV*).
- **Panduan Alur Kerja:** Langkah praktis penggunaan kombinasi website untuk pengerjaan skripsi, tugas kelompok, dan persiapan karier.
- **Bookmark Favorit & Tambah Link Kampus:** Simpan website favorit dan tambahkan link portal kampus Anda sendiri (tersimpan otomatis di `localStorage`).

## Cara Upload ke GitHub Pages
1. Ekstrak `mahasiswahub-portal-mahasiswa.zip`.
2. Buat repository baru di GitHub (misalnya `mahasiswa-hub`).
3. Upload `index.html`, `style.css`, `app.js`, dan `README.md` ke branch `main`.
4. Buka **Settings → Pages**, pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
